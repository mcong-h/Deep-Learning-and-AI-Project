# App Module

This module will eventually contain the interactive demo.

The app is intentionally not the first implementation priority. It should call the same perception and planning modules used by the experiments so that the live demo reflects the evaluated research system.

Possible workflow:
1. upload garment photo;
2. upload care-label photo;
3. inspect extracted garment profile and confidence;
4. add garment to a laundry batch;
5. compare deterministic and uncertainty-aware grouping decisions;
6. display reasons for separating uncertain garments.
