# Research Plan

## Working Title
**Uncertainty-Aware AI Laundry Load Planning**

## 1. Research Question
**Can uncertainty-aware planning reduce unsafe laundry decisions caused by imperfect garment recognition without substantially increasing the number of washing loads?**

## 2. Research Motivation
Laundry planning is naturally a multi-stage decision problem.

A perception system first estimates garment attributes such as:
- color,
- garment type,
- material,
- washing temperature,
- wash-cycle restrictions,
- other care-label constraints.

A downstream planner then decides which garments can safely be washed together.

The key issue is that AI predictions are imperfect. If the downstream planner treats every predicted attribute as ground truth, recognition errors can directly cause unsafe laundry decisions.

Our project focuses on this interface between **perception uncertainty** and **downstream planning**.

## 3. Hypothesis
We hypothesize that incorporating model confidence into laundry planning will:
1. reduce unsafe garment groupings;
2. remain reasonably efficient in terms of the number of loads;
3. outperform deterministic top-1 planning as recognition quality decreases.

## 4. Proposed Input
For each garment, the system may use two images:

### Garment photo
Used to estimate:
- color;
- garment category/type.

### Care-label photo
Used to estimate or extract:
- material composition;
- washing temperature;
- washing method/cycle;
- bleaching restrictions;
- drying restrictions;
- other care instructions.

When possible, material information should be read from the care label rather than inferred only from garment appearance.

## 5. Structured Garment Profile
A garment record may contain both predictions and confidence values, for example:

```text
color:
  black: 0.97

material:
  cotton: 0.54
  wool: 0.41
  other: 0.05

max_temperature: 30 C
delicate_cycle: true
```

The exact schema may change during implementation.

## 6. Planning Methods

### Baseline 1 — Color-only heuristic
Uses simple color-based grouping rules.

### Baseline 2 — Deterministic top-1 planner
Uses AI-predicted garment attributes but treats the highest-probability prediction as certain.

### Baseline 3 — Deterministic full-constraint planner
Uses predicted color, material, and care-label constraints but ignores uncertainty.

### Proposed Method — Uncertainty-aware planner
Uses confidence/probability information when deciding whether two garments can safely share a load.

Possible behavior:
- accept a grouping when confidence is high;
- use conservative settings when multiple likely attributes are compatible with one safe cycle;
- separate a garment when prediction uncertainty makes a grouping risky.

### Oracle Planner
Uses ground-truth attributes and constraints. This gives a reference for the best decision available if perception were perfect.

## 7. Evaluation Plan
The main evaluation should examine the tradeoff between **safety** and **efficiency**.

### Primary metrics
- **Safety violation rate**: fraction of loads that violate at least one ground-truth care constraint.
- **Unsafe-pair rate**: fraction of garment pairs grouped together despite incompatible ground-truth requirements.
- **Number of loads**: total washing loads generated by each planner.
- **Average load utilization**: how fully each load is used.
- **Decision regret vs. oracle**: difference between a planner's cost and the oracle planner's cost.

A possible combined cost is:

```text
Cost = lambda_s * safety_violations + lambda_l * number_of_loads
```

with:

```text
Regret = Cost(AI planner) - Cost(oracle planner)
```

The exact cost definition will be finalized before experiments.

## 8. Recognition-Noise Experiment
To isolate the effect of perception errors, we can simulate different recognition-quality levels, for example:
- 100% correct;
- 90%;
- 80%;
- 70%;
- 60%.

This lets us test whether uncertainty-aware planning degrades more gracefully than deterministic planning as prediction quality decreases.

## 9. Expected Contribution
We do **not** claim that garment recognition, laundry sorting, or laundry optimization are new problems.

Our contribution is to study a specific downstream question:

> How should uncertainty from AI-based garment and care-label recognition be handled when making laundry-grouping decisions?

The project connects an imperfect perception stage with a constrained decision stage and evaluates whether confidence-aware planning improves safety without excessive efficiency loss.

## 10. Initial Implementation Order

2. Implement compatibility constraints.
3. Implement oracle planner.
4. Implement deterministic planner.
5. Implement uncertainty-aware planner.
6. Build synthetic recognition-noise experiments.
